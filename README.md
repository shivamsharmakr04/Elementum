# Elementum — AI & Digital Product Studio

A modern React/Vite product studio landing experience focused on AI products, interactive interfaces, portfolio presentation, and project estimation.

## ✨ Highlights

- Dark glassmorphism visual system
- Multi-theme accent switcher
- Interactive telemetry-style hero experience
- Searchable/filterable portfolio showcase
- Project scope and cost estimator
- Multi-step inquiry flow
- FAQ search and category filtering
- Responsive UI and motion effects

## 🛠️ Tech Stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- React Icons
- Canvas Confetti

## 🚀 Run Locally

```bash
git clone https://github.com/shivamsharmakr04/Elementum.git
cd Elementum
npm install
npm run dev
```

Open the local Vite URL shown in your terminal.

## 📦 Production Build

```bash
npm run build
npm run preview
```

## 📁 Project Notes

The repository is structured as a frontend application and does not require the external GitHub account or repository referenced in older documentation.
